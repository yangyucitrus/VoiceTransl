# VoiceTransl ASMR Upgrade Handoff - 2026-07-05

本文记录截至 2026-07-05 的需求、代码、模型布局、测试结果和下一步，防止上下文限额后遗忘。

## 目标

把 `shinnpuru/VoiceTransl` 改成日语 ASMR / 成人向二次元音声字幕工具。第一阶段做 CLI 核心，不做 GUI 和打包。

管线：`本地音视频 → 16k mono wav → ASMR VAD → 日语转录 → ja.json/SRT → 在线翻译 → zh.json/SRT → 双语 SRT → 质量报告`

## 已完成

### GPU 修复

`ctranslate2 4.8.1` Windows wheel 不捆绑 cuBLAS，缺 `cublas64_12.dll`。修复：
- 装 `nvidia-cublas-cu12 12.9.2.10`（DLL 在 `.venv/Lib/site-packages/nvidia/cublas/bin/`）
- `asmr/transcribe.py` 加 `_ensure_cuda_dlls()`：Windows 下把 `nvidia/cublas/bin`、`nvidia/cuda_nvrtc/bin` 注入 PATH（`os.add_dll_directory` 单独不够，ctranslate2 C++ 端用无标志 LoadLibrary 只搜 PATH）
- `device_preset: gpu_quality`（float16），RTX 4070 8GB
- `requirements-asmr.txt` 加 `nvidia-cublas-cu12; sys_platform == "win32"`

### ASMR CLI 核心

`asmr/` 包 + `asmr_pipeline.py`：config / models / audio / vad / transcribe / translate / subtitles / dictionaries / quality / pipeline。

### ASR checkpoint + 调试参数

- `cache/asr_partial.jsonl`：JSONL 追加，每完成一个 VAD segment 立即落盘，中断可恢复（按 vad.segment_id 跳过）
- CLI 加 `--limit-segments N` / `--start-segment N`（1-based）
- 成功后自动清理 partial

### ASR 时间戳修复

- clamp ASR start/end 到 VAD chunk 范围（消除微 overlap）
- 丢弃 whisper 幻觉段（`asr_end > chunk_duration*2 且 +1s`），根治短 chunk 幻觉尾部覆盖后续段

### 翻译后检测

`asmr/translate.py` 加 `validate_translation_output`：校验 GalTransl 输出是 list、非空、每条有 message、数量 ≥ 输入。坏输出抛明确错误，标记 translation_failed，保留转录产物（ADR 0006）。

### 提示词

`translation_guidelines/ASMR_Adult_2D.md`（245 行）：任务与输出、5 条核心原则、正反例、剧情向定位、声效模式 A/B、音声拟声词映射（气息/笑声/亲密/身体/触感/湿润/撸管/睡眠/感受 8 类约 40 词）、成人向处理、二次元口语、敬语、字幕长度、禁止事项、自检。

### 字典环节

- `dictionaries/translation_glossary.txt`：GalTransl GPT 字典格式（TAB 分隔），含 プロデューサー→制作人、お兄ちゃん→哥哥、先輩→前辈、ご主人様→主人、お姉さん→姐姐
- `asmr/translate.py` 读 translation_glossary 写入 GalTransl 的 GPT字典.txt
- `dictionaries/transcription_corrections.txt`、`post_translation_replacements.txt`：空模板（带格式注释）

### GalTransl 集成修复

GalTransl 在项目根目录（git clone，不在 pip）。集成时修了多个 bug：
- `load_guideline_file` 用相对路径 `translation_guidelines/...` 依赖 cwd → translate.py 传 guideline 绝对 POSIX 路径
- `defaultDictFolder: "Dict"` 相对 cwd → 改绝对路径指向 galtransl_project/Dict
- `problemList` 枚举值：`标点错误` → `标点错漏`（CProblemType 枚举）
- GalTransl 依赖补进 `requirements-asmr.txt`：aiofiles, openai[aiohttp], opencc, openpyxl, alive_progress, InquirerPy, colorlog, tenacity, aiohttp, tiktoken, nest_asyncio, packaging

## 已知问题

1. 12 个 long_segment warning：单个 VAD 段内 ASR 长对话（最长 21s），advisory，不影响输出。
2. `resolve_device("auto")` 仍返回 `("auto","auto")`，自用场景用显式 `gpu_quality`，暂不处理。
3. 翻译无 checkpoint（只有 ASR 有），但翻译快（1-3 分钟），中断重跑即可。
4. GalTransl 翻译结果会被缓存（`cache/galtransl_project/gt_output/`），重跑可能复用旧结果。如要强制重翻，删该目录。
5. `dictionaries/transcription_corrections.txt` 和 `post_translation_replacements.txt` 是空模板，需要时填充。
